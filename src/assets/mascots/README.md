# Mascot artwork

The app ships hand-built SVG versions of the ten buddies (`src/components/mascots/MascotArt.tsx`).

To use original artwork instead, drop files here named after the mascot id:

`bear`, `cat`, `dog`, `elephant`, `fish`, `frog`, `giraffe`, `rabbit`, `turtle`, `whale`

Supported extensions: `.png`, `.webp`, `.svg`. Square images with transparent or white
backgrounds work best. Any file present here automatically replaces the built-in SVG.
